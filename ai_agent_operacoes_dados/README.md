# Dados de Apoio — AI Agent para Operações Internas

Este conjunto de dados é totalmente fictício e representa apenas uma pequena amostra da informação interna de uma empresa com cerca de 80 pessoas.

Os ficheiros foram preparados para apoiar o desafio. Não existe uma solução única nem é necessário utilizar todos os dados disponíveis.

## Ficheiros

- `employees.json` — diretório simplificado de colaboradores.
- `onboarding.md` — processo interno de onboarding.
- `access_policy.md` — regras para pedidos de acesso.
- `expenses_policy.md` — regras de aprovação de despesas.
- `tasks.json` — exemplo de tarefas internas abertas e concluídas.
- `calendar.json` — disponibilidade e reuniões de alguns colaboradores.
- `messages.json` — exemplos de pedidos e mensagens internas.

## Notas

- Não é necessário integrar serviços reais. As ações podem ser simuladas localmente.
- Não é esperado qualquer custo com APIs, modelos ou subscrições para realizar o desafio.
- Os candidatos podem trabalhar apenas com a parte dos dados que seja relevante para a solução escolhida.
- Quando a informação não for suficiente para tomar uma ação com segurança, o sistema pode pedir esclarecimentos ou validação humana.
